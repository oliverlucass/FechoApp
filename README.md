# FechoApp

Front end do FechoApp, em português do Brasil. A interface segue os quadros capturados do marketplace: início, categorias, tarefas, publicação e conta. Não há banco, login de verdade nem infraestrutura.

## Rodar

```bash
npm install
npm run dev
```

O servidor sobe em [http://127.0.0.1:43123](http://127.0.0.1:43123), escutando em `0.0.0.0`.

## Rotas

- `/` início
- `/categorias` `/como-funciona` `/ganhar` `/calculadora` `/limpeza` `/vale-presente`
- `/servicos` `/sydney` `/locais/melbourne` (e Brisbane, Perth, Adelaide, Canberra)
- `/empresas` `/parceiros` `/estudantes` `/sobre` `/carreiras` `/seguro` `/trabalhos`
- `/guias-de-preco` `/guias-de-servico` `/comparacoes` `/tendencias`
- `/diretrizes` `/principios` `/termos` `/privacidade` `/ajuda`
- `/tarefas` e `/tarefas/limpeza-fim-de-contrato`
